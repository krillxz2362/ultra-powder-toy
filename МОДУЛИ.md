# Устройство физики: семь модулей

Договор простой: у каждого модуля написано, **что он читает**, **что
пишет** и **чего не трогает**. Если модулю нужно чужое поле — он его
только читает. Писать в чужое нельзя: именно от этого код становится
непонятным.

Модули 1–3 — ядро, работают в обоих изданиях. Модули 4–7 — химия,
в издании Base её правила пустые, механика та же.

---

## 1. Контакт

**Отвечает за то, чтобы вещества не проваливались друг в друга** и
чтобы сжимались под давлением.

| | |
|---|---|
| читает | место и скорость частиц, карту клеток, плотности |
| пишет | скорости после удара, признак опоры, количество вещества в клетке |
| не трогает | температуру, реакции, воздух |

Что внутри:

* **Опора.** Проход по столбцам снизу вверх: частица опёрта, если под
  ней неподвижное тело, край мира или другая опёртая частица. Это
  цепочка контактов до земли — то, что в жизни передаёт вес.
* **Удар.** Неупругий, с сохранением импульса `u = (m₁v₁ + m₂v₂)/(m₁+m₂)`.
  Отскок бывает только от опоры: от свободно падающего соседа
  отскакивать не от чего.
* **Скольжение.** Скатывание по куче. В свободном падении кучи нет —
  там касание только сдвигает частицу вбок, не отбирая падения.
* **Сжатие — этого ещё нет.** Сейчас в клетке ровно одна частица, и
  сжать вещество нельзя в принципе. Чтобы появилось, частице нужно
  дать количество вещества: тогда в клетке газа может быть больше или
  меньше массы, а давление считается из неё и температуры.

## 2. Движение

**Отвечает за то, куда вещество едет** под тяжестью, давлением и
ветром.

| | |
|---|---|
| читает | плотности, поле воздуха, вес столба, свойства вещества |
| пишет | скорости и места частиц, поле воздуха (торможение и нагрев от частиц) |
| не трогает | реакции, температуру вещества |

Что внутри: тяжесть с Архимедом, вес столба жидкости `p = ρgh`,
боковое давление, подъём отстающего колена сообщающихся сосудов
`a = g·Δh/L`, снос ветром, перенос частиц подшагами, поле воздуха
(давление, скорость, перенос поля, конвекция по Буссинеску).

## 3. Состояние

**Отвечает за то, в каком вещество состоянии**: температура, фазовые
переходы, срок жизни.

| | |
|---|---|
| читает | температуру соседей, свойства вещества, давление |
| пишет | температуру, фазу вещества, скрытую теплоту, срок жизни |
| не трогает | места и скорости |

Что внутри: теплопроводность `Q = kΔT` с проверкой устойчивости,
скрытая теплота плавления и кипения, плавление и затвердевание,
кипение и конденсация со сдвигом точки от давления, истечение срока
жизни.

Фазовый переход — это **не** реакция: вещество не встречается с
другим, оно меняется само. Поэтому он здесь, а не в модулях 4–7.

---

# Химия: модули 4–7

Разделены по тому, **кто спрашивает** и **кто отвечает**.

## 4. Поиск

**Отвечает на вопрос «кто с кем рядом».** Ходит по частицам и находит
пары, которым есть о чём говорить: соседей по клетке, частицу и
воздух вокруг, частицу и её собственный срок распада.

| | |
|---|---|
| читает | карту клеток, вещества частиц, пометку «участвует в химии» |
| пишет | ничего — только отдаёт список кандидатов |

Сюда же попадает поиск катализатора рядом: реакция может требовать
третьего, который сам не меняется.

Дёшево это работает за счёт пометки: у вещества, не участвующего ни в
одной реакции, поиск обрывается сразу.

## 5. Проверка условий

**Отвечает на вопрос «можно ли».** Берёт пару от модуля 4, спрашивает
у модуля 6 правило и сверяет обстановку: температуру, давление,
наличие катализатора, вероятность. Если всё сошлось — запускает
модуль 7.

| | |
|---|---|
| читает | температуру, давление, окружение пары, правило из модуля 6 |
| пишет | ничего, кроме решения «да или нет» |

Здесь же — честный расход случайности: вероятность применяется не
каждый кадр, а с учётом того, что кадров много. Вероятность, которую
бросают шестьдесят раз в секунду, срабатывает почти наверняка, какой
коэффициент ни ставь.

## 6. Правила

**Свод: при каких обстоятельствах что происходит.** Это данные, а не
код — таблицы, порождаемые генератором из описаний веществ.

| | |
|---|---|
| содержит | что с чем, во что превращается, окно температур, нужное давление, катализатор, вероятность, тепловой выход |
| не содержит | ни одной строки исполнения |

Сейчас это 244 реакции, 1238 пар, 18 разложений, 16 катализаторов.
Варка алкоголя живёт здесь же обычной записью:
`C₆H₁₂O₆ + H₂O → C₂H₅OH + CO₂`, 18…45 °C.

**Почему правила — данные.** Их сотни, они меняются чаще всего, и
каждая правка не должна требовать пересборки логики. Издание Base —
это тот же код с урезанным сводом.

## 7. Исполнение

**Отвечает за то, что при реакции происходит на самом деле.** Не
«заменить вещество A на вещество B», а провести превращение по
физике: сохранить массу, выделить или поглотить тепло, поднять
давление, разлететься осколкам.

| | |
|---|---|
| читает | правило, состояние пары |
| пишет | вещества частиц, температуру, давление, скорости продуктов |

Что сюда входит: горение с расходом кислорода, кислотное растворение,
растворение соли, взрыв с ударной волной, разложение по сроку.

# Как они связаны

```
            ┌─────────── 1. КОНТАКТ ───────────┐
            │  опора, удар, скольжение, сжатие │
            └────────────┬─────────────────────┘
                         │ скорости после удара
            ┌────────────▼─────────────────────┐
            │  2. ДВИЖЕНИЕ                     │
            │  тяжесть, давление, ветер        │
            └────────────┬─────────────────────┘
                         │ новые места
            ┌────────────▼─────────────────────┐
            │  3. СОСТОЯНИЕ                    │
            │  тепло, фазы, срок жизни         │
            └────────────┬─────────────────────┘
                         │ температура и фаза
   ┌─────────────────────▼──────────────────────────┐
   │  4. ПОИСК ──► 5. ПРОВЕРКА ──┬──► 7. ИСПОЛНЕНИЕ │
   │                   ▲         │                  │
   │                   └── 6. ПРАВИЛА (данные) ◄────┘
   └────────────────────────────────────────────────┘
```

Обратная связь замыкается через поля: исполнение поднимает
температуру и давление, движение их читает на следующем шаге.

## Что уже разложено, а что ещё нет

| файл | модуль | строк |
|---|---|---|
| `world.cpp` | мир: частицы, карта клеток, пробуждение, кадр, распорядитель шага | 527 |
| `contact.cpp` | **1. Контакт** — пока только опора | 50 |
| `motion.cpp` | **2. Движение** + разбор столкновений | 650 |
| `state.cpp` | **3. Состояние** | 336 |
| `chem.cpp` | **4–7. Химия** | 152 |

**Честно про незавершённое.** Модуль 1 вынут не целиком: удар и
скольжение всё ещё живут внутри цикла переноса в `motion.cpp`, потому
что они переплетены с подшагами движения. Это следующая работа —
вытащить разбор столкновения в отдельную попытку «частица хочет
попасть в занятую клетку», которую контакт решает сам.

Так же и с химией: модули 4–7 лежат в одном файле и пока разделены
только по смыслу. Разводить их по разным файлам имеет смысл вместе с
переделкой поиска пар.

Правило на все шаги: **сперва опыт, потом правка.** Три догадки подряд
о падающем пласте были неверны; измерение нашло причину с первого раза.
