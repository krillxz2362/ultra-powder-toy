# ULTRA POWDER TOY

2D-песочница веществ: сыпь песок, лей воду, поджигай, вари химию.
Своё ядро физики, свой интерфейс, без чужих движков и ассетов.

Разработка: **krillxz2362**. Особая благодарность **AYDIK** за помощь.

## Что внутри

| | |
|---|---|
| ядро | C++17, свои массивы, событийное пробуждение кусков мира |
| интерфейс | SDL2, свой пиксельный шрифт с кириллицей |
| сборка | NDK, `arm64-v8a` и `armeabi-v7a`, Android от 5.0 |
| веществ | 326, из них 118 элементов таблицы Менделеева и 116 соединений |
| реакций | 244, плюс 18 разложений и 16 катализаторов |

Физика считается по настоящим формулам, а не на глазок: закон
Архимеда, `ρ ∝ 1/T` для газов, теплопроводность `Q = kΔT` с проверкой
устойчивости, скрытая теплота фазовых переходов, давление столба
`p = ρgh`, конвекция по Буссинеску, сообщающиеся сосуды через
`a = g·Δh/L`. Одна клетка мира — около 2 см.

## Как собрать

**Настольная сборка** (нужен SDL2):

```
cd cpp && make upt && ./upt
```

**Проверки** — ядро на C++ сверяется с эталоном на Lua число в число,
шесть опытов плюс 42 проверки физики:

```
cd cpp && make check
```

**APK** — скрипт сам доставит JDK, Android SDK, NDK и SDL2:

```
bash apk/build.sh
```

## Устройство

```
cpp/        ядро и интерфейс на C++17
  include/  заголовки; upt_substances.h и upt_chem.h создаются генератором
  src/      core.cpp — вся физика; ui.cpp — панель; main_sdl.cpp — окно
  tests/    опыты, сверяемые с эталоном на Lua
game/       эталон на LÖVE 2D: по нему сверяется каждая фаза ядра
  fiz/      sim.lua, air.lua
  data/     вещества, химия, реакции
tools/      генераторы таблиц и значков, эталонные опыты
apk/        сборка под Android
```

Эталон на Lua — не наследие, а мерило: пока фаза не сошлась с ним
число в число, она не считается перенесённой.

## Два издания

**Base** — базовые вещества. **Alcoholic** — вся химия плюс варка
алкоголя и перегонка. Физика и код общие, разнятся список веществ и
экран ХИМИЯ.

## Лицензия и заимствования

Чужой код и чужие ассеты не использованы. The Powder Toy послужил
источником вдохновения и описаний поведения, не более.
